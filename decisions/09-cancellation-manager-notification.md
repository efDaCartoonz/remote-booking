# Уведомление руководителя при отмене карточки

- **Дата:** 25 сентября 2026 г.
- **Исходный вопрос:** когда отправлять руководителю внутреннее уведомление по событию «Карточка отменена», для которого Concept и SRS оставляют контекстного получателя?
- **Решение пользователя:** «При каждой отмене».

При каждом допустимом переходе карточки в статус «Отменено» RDM создаёт долговечное внутреннее уведомление активным руководителям по их включённым каналам. Уведомление не зависит от переключателя публичного сообщения клиенту. Повтор обработки одного исходного события не должен создавать дубли, а ошибка доставки не должна откатывать отмену карточки.

## Затронутые требования

- `Docs/RDM-Concept.md` §12.3: строка «Карточка отменена» отмечает руководителя как контекстного получателя.
- `Docs/RDM-SRS.md` §12.2: для руководителя указано «При необходимости»; `REQ-FR-098` требует необходимые уведомления при отмене; `NOTIF-001`–`NOTIF-004` задают внутренние каналы и привязки.
- `Docs/RDM-ROADMAP.md`, IE-02: проверка получателей, каналов, source event, идемпотентности и устойчивости к сбою доставки.

## Последствия для кода и тестов

Добавить событие внутреннего уведомления об отмене с получателями-руководителями при каждой отмене, поддержать Telegram/Битрикс24 согласно настройкам получателя и проверить долговечное создание, повтор без дублей и сохранность бизнес-операции при ошибке доставки. Обязательные уведомления участвующих L1 и L2 проверять по действующей матрице отдельно.

## Синхронизация нормативных документов

Решение записано только в `decisions/`. По явному указанию пользователя перенос содержания решений в Concept, SRS, README и другую нормативную документацию выполняет отдельный агент-документовед; в рамках IE-02 эти файлы не синхронизированы с новым правилом. Нормативная синхронизация остаётся отдельным шагом до статуса IE-02 `DONE`.
