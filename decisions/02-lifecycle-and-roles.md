# Жизненный цикл и роли

## Решения

- Основной путь: `Создано → Назначено → Подтверждено → Выполняется → Завершено`.
- Ветки: `Отклонено` и `Отменено`. «Перенос» — операция, а не статус.
- При изменении времени или плановом переназначении подтверждённая карточка возвращается в «Назначено».
- Отсутствие ответа L2 не равно отказу: карточка остаётся «Назначено» с признаком просрочки после планового интервала.
- После отказов всех доступных L2 карточка становится «Отклонено»; L1 сопровождает согласование нового времени, руководитель получает уведомление.
- Бизнес-роль и право администратора независимы. В один момент у карточки один ответственный L2.
