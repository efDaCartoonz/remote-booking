# Таймерные напоминания и эскалации

## Утверждённые правила

- L2: якорь — `created_at` текущей серверной `assignment_attempt`; первое напоминание — через настроенный интервал, далее по исходному расписанию до конца планового интервала.
- L1 до информирования: якорь — серверное событие назначения текущего L1.
- L1 после информирования: якорь — серверное событие `client_informed = true`; используется отдельный интервал.
- При catch-up создаётся только одно актуальное напоминание. Его логический номер вычисляется по исходному якорю; пропущенные уведомления не создаются, следующий срок — ближайшая исходная точка строго после текущего времени.
- Эскалация L2 создаётся один раз для текущей попытки назначения после второго напоминания.
- Эскалация L1 создаётся после второго напоминания без `client_informed` и повторяется каждые 30 минут до информирования.
- После информирования эскалация прекращается, а напоминания L1 продолжаются с отдельным интервалом.
- Все активные расписания привязываются к snapshot настроек; новые настройки не изменяют уже начатые расписания.

## Настройки

`REMINDER_L2_INTERVAL_SECONDS=600`, `REMINDER_L2_ESCALATION_AFTER_COUNT=2`,
`REMINDER_L1_INTERVAL_SECONDS=600`, `REMINDER_L1_ESCALATION_AFTER_COUNT=2`,
`REMINDER_L1_MANAGER_REPEAT_SECONDS=1800`,
`REMINDER_L1_INFORMED_INTERVAL_SECONDS=1800`,
`REMINDER_SCAN_INTERVAL_SECONDS=60`, `REMINDER_BATCH_SIZE=100`.

Порция ограничена максимумом 500 записей. Время хранится и сравнивается в UTC.
Напоминания не меняют статус карточки. Новый цикл, перенос, переназначение,
смена исполнителя, отмена, завершение и выход из соответствующего состояния
закрывают старое расписание.
