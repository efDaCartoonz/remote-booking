# 10. FE-04: формулы отчётов и хранение параметров интеграций

Принято владельцем продукта 1 октября 2026 г.

## Отчёты (REQ-FR-146..150, 154..155)

Отчёты строятся **по событиям периода** `[from, to)` в UTC-моментах; границы
периода задаёт пользователь, дни считаются в часовом поясе профиля читающего.
Деление на ноль даёт `null`, а не 0. Права: руководитель и администратор.

| Показатель | Определение |
|---|---|
| Создано | карточки с `created_at` в периоде |
| Завершено | карточки, перешедшие в `COMPLETED` в периоде (по событию истории) |
| Доля отклонённых | карточки с ≥1 событием отказа в периоде / карточки, созданные в периоде |
| Доля повторно отклонённых | карточки с ≥2 неуспешными циклами (отказ в периоде) / карточки с ≥1 отказом в периоде |
| Просроченные | карточки, получившие признак просрочки в периоде (список и количество) |
| Срочные | карточки с `urgent_reason`, созданные в периоде |
| Срочные коллизии | события `URGENT_COLLISION` в периоде |
| Загрузка L2 | по каждому L2: число назначенных и завершённых карточек, суммарные запланированные минуты за период |

Среднее время назначения/реакции/обработки (REQ-FR-151..153) и конструктор
отчётов не входят в FE-04.

## Параметры интеграций (ADM-012, ADM-013)

Секреты (токены, webhook-URL, ключи Omnidesk/Telegram/Битрикс24) хранятся
только в окружении (`.env`) и не читаются, не пишутся и не возвращаются через
API и UI. Административный интерфейс показывает статус (настроено/не
настроено, включено/выключено) и несекретные параметры, редактируемые через
`system_settings`, а также шаблоны уведомлений.

## Параметры планирования (ADM-010)

Минимальное время до подключения (по умолчанию 120 минут), горизонт (14 дней),
длительность по умолчанию, минимальная и максимальная длительность хранятся в
`system_settings` с текущими значениями как значениями по умолчанию; один
источник чтения для всех путей создания.
