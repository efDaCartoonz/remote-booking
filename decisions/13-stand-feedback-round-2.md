# 13. Обратная связь по стенду, второй круг: список L1, напоминания, доступность L1, выбор времени

Принято владельцем продукта по итогам ручной проверки (чек-лист `STAND-ROLES-20261001`). Решение новее
SRS (REQ-FR-066/067, API-025, UI по спискам) и при конфликте имеет приоритет.

## Список «Мои карточки» для L1

- Показываются карточки, где L1 — сопровождающий **или** создатель (раньше только отклонённые и просроченные
  с ним в роли сопровождающего, поэтому свежесозданная карточка не находилась).
- Разделы: «Требуют работы» (отклонённые и просроченные; открыт по умолчанию), «В работе» (создано, назначено,
  подтверждено, выполняется, ожидает результат), «Завершённые и отменённые», «Все»; в названии — число карточек.
- Остальные действия по карточкам (перенос по желанию клиента, отмена с причиной) доступны из раздела «В работе».

## Доступность L1 при назначении сопровождения

REQ-FR-066/067 понимаются буквально: L1 должен быть доступен **в момент назначения сопровождения**, а не в
плановое время подключения. Раньше проверка шла по плановому интервалу, и при плановом времени вне смены L1
сопровождающий не назначался (карточка оставалась без владельца и не попадала в список). Доступность теперь
проверяется на текущий момент (график, отсутствия, нерабочий день); создатель имеет приоритет, иначе
глобальный Round Robin; если доступных нет — карточка остаётся «Отклонено» без сопровождающего, руководитель
получает уведомление (REQ-FR-068).

## Напоминания L1 после «Клиент проинформирован»

Интервалы: 10, 15, 30 минут, 1, 2, 4, 8 часов, раз в сутки и «Не напоминать» (`interval_minutes = 0`). Отключение
закрывает расписание и запоминается; позже можно выбрать интервал снова. Прежнее ограничение 10/30 (API-025) снято.

## Выбор даты и времени

Дата выбирается в календаре браузера (недоступные дни отключены) с подписью дня недели; время — отдельными списками
часов и минут (шаг 5 минут), в сфокусированный список можно вводить цифры. Границы берутся из параметров
планирования. Формы создания и переноса сверстаны в две колонки.

## Прочее

- Часовой пояс профиля — список с названием города и смещением UTC (например, «Екатеринбург (UTC+05:00)»).
- Несуществующий путь показывает страницу «Страница не найдена» с кнопкой «На главную».
- После успешного действия очищается только поле причины этого действия (перенос, отказ, отмена, назначение).
