# Manager-create: первый этап

Для обычных карточек руководителя используется отдельный manager-only API.
Запрос принимает только контекст обращения Omnidesk, плановое время, длительность,
описание и выбор `auto` либо конкретного L2. Сервер получает клиента только из
подтверждённого ответа Omnidesk; серверные поля карточки браузеру не доверяются.

Omnidesk preflight и обязательный reopen закрытого обращения выполняются до
транзакции RDM. Автоматический выбор использует существующий L2 distribution.
Ручной выбор повторно проверяется внутри транзакции и создаёт полный цикл
назначения, reminder schedule и notification intent без внешней доставки.

Срочность, ретроактивные и внерабочие сценарии не входят в этот этап.
